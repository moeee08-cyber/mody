# Moe & Wendi · two years in orbit

A small anniversary timeline made from the photos, videos, and notes in the original spreadsheet.

## GitHub Pages

This repository includes a GitHub Actions workflow that deploys the site from the root of . In **Settings → Pages**, set the source to **GitHub Actions**. The workflow will then publish the site after a push.

The site is static and needs no build step. Original media is in ; HEIC files use browser-friendly JPEG previews in . Videos are served in their original formats.
